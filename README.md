# Reymon Mobile Barber

Sitio bilingüe (español por defecto, inglés opcional) para una barbería móvil premium en St. Thomas, USVI.

## Configuración rápida

Edita el objeto `BUSINESS` al inicio de `src/App.jsx`:

- `phoneDisplay`
- `phoneHref`
- `whatsappNumber`
- `instagramUrl`
- `bookingUrl`
- `email`
- `musicUrl`

La música es opcional y **no se reproduce automáticamente**. Usa únicamente audio con licencia o propiedad del negocio.

## Galería

Reemplaza las URLs del arreglo `gallery` en `src/App.jsx` por fotografías reales del trabajo de Reymon.

## Ejecutar

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```
